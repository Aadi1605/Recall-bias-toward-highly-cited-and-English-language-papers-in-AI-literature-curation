# GitHub Implementations — Recall Bias in AI Literature Curation

- **[allenai/specter](https://github.com/allenai/specter)**
  Official implementation of SPECTER (Cohan et al., 2020) — citation-informed
  document embeddings — with pretrained models and a link to the SciDocs
  evaluation framework.

- **[allenai/SPECTER2](https://github.com/allenai/SPECTER2)**
  Successor to SPECTER with task-specific adapters (classification, regression,
  retrieval); relevant for building citation-aware retrieval baselines to compare
  against citation-neutral approaches.

- **[allenai/scibert](https://github.com/allenai/scibert)**
  Official pretraining/fine-tuning code for SciBERT (Beltagy et al., 2019),
  foundational for scientific-text NLP.

- **[allenai/s2orc](https://github.com/allenai/s2orc)**
  Tools and documentation for working with the S2ORC corpus (Lo et al., 2020),
  useful for reproducing the infrastructure-composition argument in the paper.

- **[allenai/scidocs](https://github.com/allenai/scidocs)**
  Evaluation suite accompanying SPECTER; relevant for benchmarking any
  citation-aware vs. citation-neutral ranking comparison.
