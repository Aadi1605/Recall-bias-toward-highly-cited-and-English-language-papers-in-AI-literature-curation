# Tools and Libraries — Recall Bias in AI Literature Curation

- **[SPECTER / SPECTER2](https://github.com/allenai/specter)** — Citation-informed
  document embedding models for scientific papers, usable via HuggingFace transformers.
- **[SciBERT](https://github.com/allenai/scibert)** — Pretrained BERT model for
  scientific text, foundational for downstream scientific NLP tasks.
- **[OpenAlex API](https://docs.openalex.org/)** — Free API for querying the
  OpenAlex scholarly graph (works, authors, venues, concepts).
- **[Semantic Scholar API](https://api.semanticscholar.org/)** — API for paper
  metadata, citation graphs, and precomputed SPECTER embeddings.
- **[SciDocs / SciRepEval](https://github.com/allenai/scidocs)** — Evaluation
  frameworks for benchmarking scientific document embedding models.
